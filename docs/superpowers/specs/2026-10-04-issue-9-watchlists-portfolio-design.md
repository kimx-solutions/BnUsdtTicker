# Issue #9：自選分組與手動持倉追蹤

- 日期：2026-10-04（Asia/Taipei）
- 來源：https://github.com/kimx-solutions/BnUsdtTicker/issues/9
- 使用者已確認聊天中的設計方向；本文件待確認後進入實作計畫。

## 目標與範圍

使用者依用途管理多個自選分組，在報價視窗快速切換，並以手動維護的數量與平均成本查看持倉變化。資料僅保存本機，不增加帳戶登入、帳戶同步或下單。沿用 WPF/MVVM、深淺主題、Fix/Float、價格提醒與歷史走勢。

## 資料設計與遷移

AppSettings 保存分組清單、目前分組 ID 與每幣種共用持倉。分組使用穩定 ID，名稱去除頭尾空白且不可為空或重複；每組成員保存 symbol、enabled 與 order，同組不可重複幣種，跨組允許重複。每組保存欄位排序方向及顯示偏好（漲跌幅、緊湊模式、走勢顯示與時段），重啟及切換可還原。

保留全域 Symbols 作為唯一幣種／提醒登錄，不在分組複製價格提醒。持倉以正規化交易對為鍵，每筆包含 decimal 數量及 decimal 平均成本（USDT／單位）。數量及成本接受零，拒絕負數、非數字與 decimal 範圍外輸入；空白代表未設定持倉，不等同明確輸入零。編輯介面說明小數点使用 .，不使用千分位。

舊設定缺少分組欄位時，自動建立「預設分組」，按原順序複製全部幣種（含停用成員）及其啟用狀態，沿用原顯示偏好；全域提醒、已觸發狀態、提醒策略與紀錄不變。持倉初始未設定。有效的新版空分組不得誤判成舊版設定。至少保留一個分組，最後一組不可刪除；失效的目前分組 ID 回退第一組。設定以既有原子寫入流程保存，Copy 深複製新資料，取消編輯不可改動原設定。

## 分組與持倉操作

設定視窗加入分組選擇、建立、重新命名與刪除操作，原幣種新增驗證、移除、啟用與上下移動改為操作選取分組。新增已存在其他分組的幣種時沿用共用資料。於設定介面編輯共用數量與平均成本，可清除持倉；修改立即反映於編輯副本中的各分組，僅儲存後套用正式資料。

刪除分組需在操作前清楚顯示：「只刪除此分組及其成員檢視；共用持倉、其他分組與價格提醒會保留。按儲存後生效。」移除成員同樣不刪除共用資料。刪除目前分組後選取第一個剩餘分組；取消則恢复原本資料。無分組引用的持倉仍可由共用持倉編輯區查看、清除，也列入全部持倉摘要。

主報價視窗加入快速分組選擇與可收合的持倉摘要／列資訊。零持倉與未設定持倉有明確不同文字。分組切換保存目前選擇，不重啟行情、不重設提醒；若寫入失敗，保留原選擇並提示。長清單使用捲動區，固定操作項仍可用；摘要採垂直排列／收合，避免在最小 360 × 260 DIP 視窗擠壓控制項。

## 行情與提醒生命週期

行情需求取所有分組 enabled 成員、正數持倉及已啟用提醒所需幣種的聯集，按 symbol 去重。提醒沿用全域 Symbols.Enabled 作為停用門檻；舊版停用幣種遷移後保持提醒停用，單純切換分組或隱藏某組成員不改變全域提醒門檻。已設定價格或短期漲跌幅條件的啟用提醒，即使分組已刪除仍維持報價來源。沒有任何需求時不建立行情訂閱。

報價先更新全域、依 symbol 去重的快取並拒絕更舊時間戳，再獨立送入提醒及持倉計算；不可因當前分組未顯示該幣種而跳過提醒。分組只是選取快取中要顯示的列。走勢補載需求限於當前可見走勢及開啟的詳情視窗，避免對純持倉／提醒額外補載走勢。設定儲存後僅在行情需求集合改變時重啟訂閱，單純持倉成本修改不重啟行情。

儲存一般設定時合併最新提醒狀態，避免覆寫編輯期間的提醒觸發或獨立警示視窗變更。保留現有視窗位置、尺寸、主題與桌面偏好提交／回復行為；未編輯的當前分組顯示偏好應保留主窗最新操作。

## 計算與狀態

使用獨立持倉計算服務及 decimal：市值 = 數量 × 現價；成本總額 = 數量 × 平均成本；未實現損益 = 數量 ×（現價 − 平均成本）；百分比 = 損益／成本總額 × 100。只在顯示時格式化與四捨五入，不提前截斷。decimal 溢位顯示「超出可計算範圍」並標示摘要不完整，不使報價流程中止。

數量為零：市值與損益為 0、百分比為「—」，標示「無持倉」，不需要現價。正數量且零成本：有報價時照常計算市值與損益，百分比為「—」，標示「成本為零」。正數量無報價：市值、損益與百分比皆為「—／等待報價」，不得使用零價格替代。連線中斷或報價超過既有 60 秒門檻時保留最後價格計算，但列與摘要標示「使用最後報價」，附更新時間；狀態隨連線／時間變化刷新。

目前分組摘要計入該組所有成員的共用持倉（含隱藏成員），明確標示「本組全部成員」；全部持倉摘要計入所有已設定共用持倉，按 symbol 去重，包含已不屬於任何分組的持倉。沒有持倉時顯示「尚未設定持倉」。有正數量持倉缺報價或溢位時，顯示可計算部分的市值／損益小計與缺失數量，完整總值與百分比顯示「—」，不可把小計宣稱完整總額。完整摘要百分比依合計成本加權计算，不平均各列百分比；合計成本為零時為「—」。
